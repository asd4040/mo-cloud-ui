# MoCloud 前端开发包

本仓库用于发布 MoCloud 嵌入式应用开发库和示例项目。

## 下载

| 内容 | 用途 | 下载 |
|---|---|---|
| 开发库 | 放入你自己的 React 项目，包含 UI Kit、Bridge SDK、Schema 和配置示例 | [下载 `mo-cloud-ui.zip`](https://raw.githubusercontent.com/asd4040/mo-cloud-ui/main/downloads/mo-cloud-ui.zip) |
| 商城 Demo | 可直接运行的完整 React 示例，已经包含开发库 | [下载 `mo-cloud-shop-demo.zip`](https://raw.githubusercontent.com/asd4040/mo-cloud-ui/main/downloads/mo-cloud-shop-demo.zip) |

- 开发库解压目录：`mo-cloud-ui-main`
- 商城 Demo 解压目录：`mo-cloud-shop-demo`

安装、配置和 Bridge 使用说明请在 MoCloud Developer 的文档中心查看。
